# Menta — risorse locali V7.7

`menta-base.webp` conserva la mascotte fornita nel progetto: rimozione del solo sfondo esterno e ottimizzazione WebP. Il volto non è ridisegnato.

`accessori.svg` contiene sei simboli vettoriali: lente, libro, tocco universitario, zaino, cuffia/telefono e checklist. Sono sovrapposti alla base nei soli contesti di orientamento utili. L’ascolto usa una variazione di orientamento della base; accoglienza e ricerca restano riconoscibili.

Otto composizioni contestuali, non otto nuovi disegni indipendenti. Tutte le figure sono decorative: `alt=""`, `aria-hidden="true"` e testo adiacente esplicito. Nessuna informazione clinica è affidata all’espressione della mascotte. Nessuna animazione necessaria.
